# ✨ Happy Birthday Jannatul Firdaus Rumali ✨
### Celebrating 18th September 🎂

A luxury, interactive, starlight-themed birthday web experience crafted for **Jannatul Firdaus Rumali**.

---

## 🌟 Key Features

- 🌌 **Dynamic Stardust & Cosmic Particle Canvas**: Twinkling stars and interactive cursor aura.
- 👑 **Editorial Typography & Midnight Velvet Aesthetics**: Luxury gradients, frosted glassmorphic panels, and glowing gold accents.
- 🎂 **Interactive 3D Birthday Cake & Candle Ritual**: Multi-tiered cake with animated flickering flames, tap to blow candles, realistic smoke wisps, fanfare music, and fireworks.
- 💌 **Wax-Sealed Letters & Wishes**: 4 interactive vintage wax seals (`JFR`) that break open to reveal custom handwritten prose & du'as.
- 💎 **"Why Rumali is One in a Billion"**: 3D interactive charm cards and daily affirmation generator.
- 📸 **Polaroid Memory Wall**: Aesthetic photo frames with washi tape, story viewing lightbox, and live custom photo upload preview.
- ✍️ **Interactive Wish Board**: Visitors can post birthday messages with sticker badges (`👑`, `✨`, `💖`, `🎂`), stored persistently in `localStorage`.
- 📜 **Honorary Birthday Keepsake**: Downloadable high-resolution royal certificate ready to save or share.
- 🎵 **Built-In Soundscape & Synthesizer**: Web Audio API ambient birthday melody, magical chimes, firework bursts, and mute/unmute controls.

## 🚀 Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build
```

## 🌐 Deploying to Netlify

This project is pre-configured with `netlify.toml` for zero-configuration Netlify deployment.

### Option 1: Git Integration (Recommended)
1. Push this repository to GitHub / GitLab.
2. Log in to [Netlify](https://app.netlify.com/) and click **Add new site > Import an existing project**.
3. Select your repository. Netlify will auto-detect the build settings:
   - **Build command**: `npm run build`
   - **Publish directory**: `dist`
4. Click **Deploy Site**!

### Option 2: Netlify Drop (Instant Drag & Drop)
1. Run `npm run build` in your terminal.
2. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
3. Drag and drop the generated `dist/` folder into Netlify.
4. Your site is live in 10 seconds!
